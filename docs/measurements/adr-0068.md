# ADR 0068: the final measurement (Phase 5a)

This is the record that
[ADR 0068](../adr/0068-a-dynamic-value-is-inspected-in-cove-not-walked-in-rust.md)'s
Phase 5 asks for: "Publish the final static-versus-reflected counts and
performance report". It is kept outside the ADR so that the ADR's body stays
exactly as it was decided. The ADR's header links here, and that is the only
change made to the ADR.

Measured on 2026-09-25 by Phase 5a. **No code changed.**

## Summary

- **Semantics.** AST, VM and native agree everywhere this repository checks:
  - `vm_coverage`: 248 of 248 programs that lower agree, with an empty
    known-disagreement set;
  - the e2e suite passes, with 39 cases compared on native;
  - both differential suites pass;
  - `cove test` in `examples/`: 223/223 on each backend.
- **Every ratchet movement is attributed to a PR.** No movement is left
  unexplained.
- **covefmt and cq did not get slower.** covefmt is identical in every VM
  counter except 19 instructions (#510). It is faster on native, where
  native→VM crossings went from 280,486 to 0. cq pays the accepted Float
  rendering cost on the VM (+0.52% / +0.82% instructions) and is 2.9% / 6.8%
  faster on native.
- **Four costs have not been accepted, and they block Phase 5**:
  - [#512](https://github.com/myuon/cove/issues/512) and
    [#513](https://github.com/myuon/cove/issues/513): static-path path
    tracking on self-reachable layouts;
  - [#514](https://github.com/myuon/cove/issues/514) and
    [#515](https://github.com/myuon/cove/issues/515): dynamic-path costs that
    no one has explicitly accepted.
- **One Phase 5 item is not done.** The dead Rust walkers are still in the
  tree: [#516](https://github.com/myuon/cove/issues/516).
- **So ADR 0068 stays `Proposed`**, and Phase 5 is recorded as blocked on
  those five issues. See the checklist at the end.

## Method

**Binaries.**
- Each commit below was built once, with
  `cargo build --profile checked -p cove-cli --features cove-cli/template`,
  in its own `git worktree` under `/tmp`, one build at a time.
- `-p cove-bench` was added for 18d92bd and 662010e.

| role | commit |
| --- | --- |
| before ADR 0068 (Phase 0 pinned, no behaviour change) | 18d92bd (#491) |
| after | 662010e (#511) |
| every step between | b57f62d (#495), e0c61ad (#496), 719bd0b (#498), 425d6e9 (#500), 28fe1db (#502), 3851211 (#503), 9ced5b7 (#507), 23aeca7 (#508), e8d5e9b (#509), 9270590 (#510) |

**One pristine tree.**
- Every binary ran over a single `git worktree` at 662010e.
- That tree was never written to. cq's input and output lived in a directory
  outside it.
- This is the hazard where covefmt walks the directory in raw order and reads
  every entry.
- The only source difference between 18d92bd and 662010e outside the compiler
  is the new rows in `benches/equals`, `benches/rendering` and
  `benches/admission`. The old binaries run those rows as they are.

**Inputs.**
- covefmt: `cd examples && cove run covefmtBench --files-root ..`, which is
  363 files and 1,750,921 bytes.
- cq `confirmed-bookings`: 100,000 records from
  `cqSample -- 100000 bookings-large.jsonl`.
- cq `rate-card`: the 20,000× `rates.csv` of ADR 0046, 120,000 rows.

**Counters** come from `--stats --boundary`. They were taken once per binary
and backend, because instructions, allocations, words and crossings are
deterministic.

**Wall time** was measured as follows:
- trials are interleaved, and binaries are rotated within each trial;
- nothing else ran during a trial;
- each figure is written `median (min–max)` with its trial count.

**Noise controls.**
- **A/A.** 662010e's binary was copied to a second path.
- **Rebuild.** 23aeca7 against e8d5e9b. #509 changed nothing covefmt executes,
  and covefmt's `--stats --boundary` counters are identical between those two
  builds on both tiers.
- On the bench rows, the builds whose instruction counts are identical show
  how far layout alone moves a row. That spread is quoted beside each claim.
